# Handoff prompt

Paste this into a new chat in Claude Desktop on the new user's computer. Change the two words in brackets.

---

I'd like to set up Cheetah Accounting, a free open-source tool my [son / brother] uses, to help me sort out my
South African tax (and my business's, if I have one) with you. I use a [Windows / Mac] computer and I am not
technical, so please guide me one small step at a time and wait for me to say "done" before the next step.

The setup guide is here: https://github.com/Skermunkel/Cheetah-Accounting/blob/main/docs/SETUP.md
Please read it and walk me through steps 1 to 4. You cannot run anything on my computer yourself, so tell me
exactly what to click, type or paste.

When I have restarted Claude Desktop and the cheetah tools appear, start the cheetah-init process: call the
cheetah_status tool and then follow cheetah_guide("init").

---

If Claude cannot open the link, paste the contents of docs/SETUP.md under the prompt instead.
