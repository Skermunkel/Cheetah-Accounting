# Catching up: penalties, debts and asking SARS for relief

## What happens when returns are late
- **Administrative (fixed) penalties**, Tax Administration Act s210/s211: a monthly amount per outstanding return,
  from R250 to R16,000 a month depending on taxable income, for up to 35 months. They apply to companies and to
  individuals named in SARS's public notice (individuals with two or more outstanding returns: check the current
  notice).
- **Late payment**: 10% penalty on VAT and PAYE paid late, plus interest on all late tax.
- Refunds are set off against debts on other tax types (s191): file refund returns too.

## Order of work
See `cheetah_guide("init")` step 4. Short version: letters with deadlines, then returns that keep adding penalties
(oldest first), then the current year, then relief requests.

## Asking SARS to cancel penalties (remission)
- On eFiling: request remission (RFR) for each penalty, after the related return is filed.
- Grounds SARS accepts for fixed penalties (s218): it is the first time (first incidence, where SARS's rules allow);
  or exceptional circumstances that stopped the person complying (serious illness, disaster, death in the family,
  serious financial hardship, SARS system errors). Explain the circumstances honestly, with dates and evidence.
- Interest is generally not remitted.
- Motivation letter (`cheetah_save_letter`): what happened and when, what has been done to fix it (all returns now
  filed, books in order), what is in place so it does not happen again, and the request. Facts only, no
  exaggeration; the person signs and dates it on the day.

## Can't pay
- **Instalment agreement** (s167): request on eFiling with a realistic monthly amount and a budget.
- **Compromise** (s200): only in serious hardship; needs a practitioner.
- Contact SARS before a debt is handed over: payment arrangements are easier before collection steps.
