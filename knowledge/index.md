# Cheetah guides

Read a guide with `cheetah_guide("<topic>")` only when the work needs it.

| Topic | Use it for |
|---|---|
| init | First-time setup interview: who, what is outstanding, what to file first, folders and Projects |
| ground-rules | Rules for every chat (also a Project file) |
| documents | Getting documents in; reading them cheaply; bank statement checks; IRP5 codes |
| bookkeeping | Bank lines to categorised books and a year summary; mixed-use costs; notes for missing slips |
| zoho-books | Zoho Books Free plan: connecting Claude, monthly routine, year-end, write safety |
| personal-tax | ITR12 step by step; common deductions and credits |
| company-tax | AFS, ITR14, director's loan, salary, CIPC annual return and BO |
| vat-paye | VAT201 and PAYE/EMP201 basics |
| catch-up | Late returns, penalties, remission letters, payment arrangements |
| records | What records to keep and for how long; software is not required |
